# Next.js and Node.js versions: 2026-10-29

The latest stable targets verified for this change are Next.js 16.4.3 and Node.js 26.13.0. Local version files, existing CI jobs, container images and package engines are aligned with Node 26. The engine range is `26.x`; exact local and CI pins are `26.13.0`.

| Application | Target branch Next.js | Proposed Next.js |

Vercel's published `@vercel/build-utils` 15.1.1 includes `nodejs26.x`. Its selector requires explicit Node 26 intent while Node 24 remains the default without the rollout flag. This branch therefore uses `engines.node: "26.x"`. Provider-managed minor and patch releases remain controlled by the host. [Runtime selector source](https://github.com/vercel/vercel/blob/main/packages/build-utils/src/fs/node-version.ts).
